# 通知播报模式与班级课表设计

## 目标

本次在班级广播中增加两项互相独立、但共同改善教室大屏日常使用体验的能力：教师发布即时通知时可以选择“文字＋语音”或“仅文字（静音）”；教室端没有正在展示的通知时，显示该班周一至周五课程表，并明确突出今天这一列。

课表属于班级共享资料，由教师在现有教师端“班级管理”中设置。它不依赖班级花名册、不复用教师个人课表，也不新增另一套登录或管理入口。

## 通知播报模式

教师端即时通知表单增加二选一的分段选择：

- `文字＋语音`：默认选项，保持现有到达提示音、腾讯云/浏览器语音播报和 1～10 次重复设置。
- `仅文字（静音）`：大屏全屏展示通知文字，但不播放到达提示音，也不调用任何语音合成；重复次数输入变为不可用。

通知数据增加 `broadcast_mode` 字段，合法值为 `voice` 与 `text`。接口收到缺失或未知值时按 `voice` 处理，以兼容历史通知和旧版教师端。通知历史记录显示“语音 × N 次”或“仅文字”，重发沿用原通知模式。

仅文字通知先按现有动画进入全屏展示，阅读停留时间按内容长度控制在 8～20 秒之间，随后进入现有缩小状态，再按现有队列规则自动关闭。它仍然进入通知历史、计入今日通知数，并保留教室端“收到／已完成”的回复入口。

## 班级课表模型

首版课表固定为周一至周五，采用 12 个中学日常时段：早读、第 1～8 节、晚自习 1～3。每个单元格保存一段最多 30 个字符的课程或安排文字，允许留空。

课表按班级保存为：

```json
{
  "version": 1,
  "entries": {
    "mon": ["语文", "数学"],
    "tue": ["英语", "物理"]
  },
  "updated_at": "2026-08-30T08:00:00.000Z"
}
```

五个工作日始终规范化为各 12 个字符串。服务端只接受固定日期键并限制每格长度，避免任意字段进入数据库。课表放入班级表已有的 `extra_json` 扩展字段，并由专门的课表读写函数管理，不新增数据库迁移。班级对象只持久化课表这一项扩展数据，避免把临时在线状态等字段误写入数据库。

## 权限与接口

新建 `timetable-routes.js`，沿用本项目 installer 模式，在 `server.js` 集中安装：

- `GET /api/classes/:classId/timetable`：该班创建者和协作老师都可读取。
- `PUT /api/classes/:classId/timetable`：仅班级创建者可修改，且需要有效会员状态。

保存成功后服务端更新内存班级对象、原子写入 SQLite，并向 `class:<classId>` 房间广播 `class-timetable-update`。教室大屏不需要轮询，绑定成功时直接从 `bind-success` 获得当前课表，之后实时接收更新。

## 教师端体验

“班级管理”页面新增独立的“班级课程表”卡片：先选择班级，再以可横向滚动的表格编辑周一至周五。第一列固定显示时段，手机上仍可逐格填写；每格使用简短文本输入框。协作老师能看到课表，但编辑区只读，并提示“由班级创建者维护”。

提供“保存课表”和“清空本班课表”两个动作。清空前二次确认，保存后立即向已连接的教室端同步。没有班级时显示引导文案，不要求先开启积分管理或导入花名册。

## 教室端体验

空闲页保留左侧班级名称、时钟、日期、状态和推广二维码。右侧改为纵向布局：设置过课表时，上方显示“本周课程表”，下方保留紧凑的班级告示栏；尚未设置任何课程时隐藏课表板块，告示栏继续占满右侧空间，维持现有体验。

课表采用“时段 × 周一至周五”网格。当天列使用浅金背景、加深边框，并在列头显示“今天”；其他日期保持米白底色。周六、周日不错误高亮任何一列。大屏收到课表更新后原地重绘，不刷新、不解除绑定。

## 数据兼容与安全边界

- 历史通知缺少 `broadcast_mode` 时一律视作语音通知。
- 历史班级没有课表时返回规范化空课表，不影响绑定和告示栏。
- 课表内容经过长度、类型和固定键校验；前端渲染统一转义，不执行教师输入的 HTML。
- 仅文字模式不会请求 `/api/tts`，从数据流上保证静音而不是把音量设为零。
- 课表与通知模式都复用现有 SQLite、登录态和 Socket.IO 房间，不引入新依赖。

## 验收

1. 教师能发布语音通知和静音文字通知；大屏只有前者会触发提示音与语音合成。
2. 旧通知仍能正常展示、朗读和重发。
3. 班级创建者能保存、修改和清空周一至周五课表；协作老师只能查看。
4. 大屏首次绑定即可显示已有课表，教师保存后无需刷新便实时更新。
5. 今天列在周一至周五正确高亮，周末不高亮；无课表时原告示栏布局正常。
6. 教师端课表编辑器可在手机宽度横向滚动使用，教室端在常见 16:9 与较矮屏幕不溢出。
7. `npm test` 串行完整回归通过，且不得破坏腾讯云 TTS、班级积分、告示栏和现有通知队列。
