# 教室广播前端视觉刷新

## 目标

在不改变教室端绑定、广播、告示、快捷回复、班级积分与 60 秒自动返回逻辑的前提下，提高教室大屏和老师端的整体质感。

视觉不是追求“炫”，而是让它像一块长期常驻教室的专业信息终端：日常安静、信息清楚、广播出现时有足够强的注意力。

## 视觉方向

采用“深墨控制台 + 暖米白信息纸面 + 琥珀金强调”的编辑式信息中枢风格。

- 深色背景负责降低常驻大屏的视觉干扰。
- 告示栏作为日常页唯一的大面积亮面，形成明确主次。
- 暖金只用于连接状态、当前操作、选中学生和关键按钮，不铺满界面。
- 中文标题使用宋体气质，数字与系统信息使用清晰的无衬线字体，兼顾品牌感与远距离辨识。
- 减少套娃卡片、粗边框、渐变按钮和过多圆角。

## 教室端

日常页保留时钟、日期、班级、告示、二维码和积分入口。时钟区去掉大卡片外框，让左侧成为安静的深色信息区；告示栏改为轻纸面，并提高通知文字对比。二维码缩小但保持完整可扫，积分入口收束成底部操作坞。

积分页保留现有座位与规则结构。深色标题栏负责导航和状态，米白工作区负责学生与规则；选中学生改为深色反转状态，避免只靠浅金描边判断。排行榜和流水使用同一套层级。

广播页降低复古装饰和粗重渐变，保留助理形象与大字号气泡，让通知本身成为唯一焦点。

## 老师端

老师端不重排信息架构，只统一背景、卡片、表单、导航、主按钮与积分管理的视觉语言。发布路径与已有操作位置保持不变，避免视觉升级带来学习成本。

## 验收

- 1366×768 与 1920×1080 下，教室日常页没有遮挡和溢出。
- 二至五米距离能辨认时间、告示标题、学生姓名和积分规则。
- 二维码完整显示。
- 纯广播班级不出现积分入口；开启积分的班级保留 60 秒自动返回。
- 键盘焦点清晰，并尊重系统“减少动态效果”设置。
