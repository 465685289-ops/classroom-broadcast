# 布尔迪厄人物 Skill 与思想圆桌八人谈设计

## 目标

用女娲造人流程蒸馏皮埃尔·布尔迪厄的思维框架，生成一份可独立运行、来源可追溯的人物 Skill，并将其压缩为适合多人短发言的角色提示词，作为第八位常驻思想者上线到思想圆桌。

上线后保留马克思、王阳明、庄子、福柯、巴菲特、鲁迅和当代教育研究者，产品名称从“七人谈”统一改为“八人谈”。一个完整话题仍消耗 50 师行积分。

## 当前基线

- 本地文件 `public/roundtable/index.html` 与生产文件 `/home/admin/classroom-broadcast/public/roundtable/index.html` 的 SHA-256 均为 `0d3f2b488b312320d23065751ba66b166b26f5b2fb901b8591367b4c007af3ee`。
- 七位人物的展示信息、提示词、选择按钮和点名识别都在同一静态页面中；后端只负责鉴权、扣费、发言次数上限、模型流式转发和实录保存。
- 单话题后端发言上限为 24 次。八位首轮发言加最多两轮全员交锋正好为 24 次，不需要修改共享后端上限。
- 本地仓库存在大量用户已有修改和未跟踪文件。本次只触碰明确列出的设计、测试、圆桌页面和人物 Skill 文件，不清理或覆盖其他工作。

## 方案选择

采用“完整人物 Skill + 圆桌精简投影”。

完整人物 Skill 保存研究证据、心智模型、表达 DNA、决策启发式、内在张力和诚实边界；圆桌页面只使用经过验证的短提示词，保证每次发言聚焦、长度可控，并与现有七位人物协议兼容。

不把全部人物迁移到后端角色库。本次静态接入可以避免修改 `server.js`、数据库和共享进程，也不需要重启共用服务。

## 调研与来源

按女娲流程从六个维度并行收集材料：著作、长对话、表达 DNA、外部评价与批评、关键学术选择、时间线。布尔迪厄是历史人物，不追求“最近动态”，而是重点核对其思想转折、概念成熟过程及不同著作之间的变化。

来源优先级为：本人著作与论文、本人访谈和讲座、可核验的学术机构资料、同行研究与批评。知乎、微信公众号、百度百科和无法追溯原文的二手摘录不作为证据。每份研究文件都区分“布尔迪厄本人表述”“他者评价”和“基于材料的推断”，并保留相互冲突的解释。

核心一手语料至少覆盖《区分》《实践理论大纲》《实践感》《再生产》《学术人》《帕斯卡尔式的沉思》《反思社会学导引》《科学之科学与反思性》《论电视》等代表性阶段；最终以实际检索到且可核验的版本为准，不以书目罗列代替阅读证据。

## 提炼目标

候选概念必须通过跨领域复现、生成力和排他性筛选，最终保留 3 至 7 个真正能指导新问题判断的心智模型。预期候选包括但不限于：

- 惯习：历史如何沉积为身体化倾向，并生成看似自然的选择。
- 场域：行动不是孤立发生，而是在有位置、规则和争夺对象的关系空间中发生。
- 资本及其转换：经济、文化、社会与象征资本如何积累、兑换并被误认为个人天赋。
- 再生产：教育和文化制度如何在形式平等下延续差异。
- 象征暴力与误认：支配关系如何被被支配者和支配者共同体验为自然、正当或有品位。
- 反思社会学：分析者也处在场域中，必须把自己的位置和分类工具纳入分析。

这些只是待验证候选，不在调研完成前预设为最终结论。

## 圆桌角色协议

圆桌中的布尔迪厄使用 `bourdieu` 作为稳定 ID，显示名为“皮埃尔·布尔迪厄”，简称匹配“布尔迪厄”。人物卡采用与现有七位可区分的颜色和“布”字头像。

提示词从完整 Skill 投影，至少包含：

- 先分析关系而非给人贴道德标签，追问行动者处在什么场域、占据什么位置、掌握何种资本。
- 把“天赋、品位、选择、努力、规则公平”等自然化表述重新放回历史和制度条件中。
- 能与马克思讨论资本和阶级，与福柯讨论权力和知识，与教育研究者讨论学校、评价与证据。
- 用可理解的中文解释术语，每次最多引入少量必要概念，不把发言写成术语清单。
- 明确承认其框架可能过度强调结构再生产、低估偶然性和个人突破，也可能把具体的人压缩成位置与资本。
- 发言遵守现有 200 至 350 字协议；被点名时针对对方的具体论点回应。

不得编造布尔迪厄原话。圆桌发言是基于经验证框架的推演，不冒充历史原文。

## 页面与交互改动

只修改 `public/roundtable/index.html`：

- 把页面标题、描述、隐藏标题、顶部标题、空状态和积分说明中的“七人”统一改为“八人”。
- 在侧栏增加布尔迪厄人物卡，在选择栏增加布尔迪厄按钮，在 `CHARACTERS` 中增加完整角色配置。
- “所有人”自动包含八位人物；单独选择布尔迪厄时只调用该人物。
- 将点名收集和点名高亮从写死的人名正则改为由 `CHARACTERS` 生成。匹配简称与显示名的映射统一放在人物配置中，避免新增人物时遗漏某一处正则。
- 保持现有登录、扣费、流式输出、上下文长度、实录保存和最多两轮追加交锋不变。

八位首轮发言会比七位多一次模型请求，等待时间和模型成本相应增加；用户积分价格不变。服务端 24 次上限覆盖最坏情况下的八位首轮加两轮全员交锋。

## 数据流与错误处理

用户选择人物并提交话题后，现有 `/api/roundtable/start` 仍只扣一次 50 积分。前端按选中人物顺序调用 `/api/roundtable/speak`，每次发送该人物的系统提示词和当前实录。布尔迪厄与其他人物走完全相同的数据流，不新增接口和数据表。

任一人物发言失败时沿用现有气泡内错误提示，其他已完成发言保留。点名解析只接受已配置人物的简称或显示名，未知 `@` 文本不触发额外调用。

## 测试策略

遵守测试先行：先新增圆桌页面测试并确认因缺少第八位而失败，再做最小页面改动使其通过。

定向测试覆盖：

- 页面所有产品文案均为“八人谈”或“八位思想者”，不存在残留的用户可见“七人”文案。
- `CHARACTERS` 包含八个稳定 ID 和布尔迪厄配置。
- 侧栏人物卡、选择按钮和“所有人”路径能包含布尔迪厄。
- `@布尔迪厄` 与 `@皮埃尔·布尔迪厄` 都能被动态解析、触发交锋并正确高亮。
- 内联脚本可被 JavaScript 引擎编译，页面现有登录、积分和邀请契约不变。

完成定向测试后运行当前完整测试集，并在桌面和窄屏视口检查第八张人物卡、横向选择栏、输入区和消息区不重叠。

## 女娲质量门槛

调研完成后先展示六维来源数量、关键发现、矛盾点和信息不足维度，取得用户确认后才提炼。提炼完成后再展示心智模型、启发式、表达 DNA、核心张力和诚实边界，取得确认后才构建 Skill。

最终 Skill 必须满足：3 至 7 个有证据的心智模型、每个模型包含失效条件、至少 3 条具体诚实边界、至少 2 对内在张力、一手来源占比高于 50%。已知立场测试、边缘问题测试和声音辨识测试通过后，再进行双视角精炼。
