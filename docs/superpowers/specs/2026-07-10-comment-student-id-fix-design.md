# 评语系统学生按钮失效修复设计

## 问题

花名册保存接口把学生 ID 转为字符串。页面重新载入花名册后仍保留字符串 ID，但学生卡的内联事件把纯数字字符串以数字参数传给处理函数。处理函数使用严格相等查找学生，因而找不到目标，导致标签、单条生成、复制、删除和字段编辑等操作无声失效。

## 方案

前端把所有学生 ID 规范为字符串，并用一个统一的 `studentIdArg` 辅助函数生成可安全嵌入 HTML 属性的 JavaScript 字符串参数。所有学生卡事件都通过该辅助函数传参，处理函数继续使用严格相等，保持类型契约清晰。

不修改数据库、不迁移既有花名册，也不改变评语生成接口或扣费逻辑。

## 验证

新增静态页面回归测试，验证：

- `normalizeStudent` 会将服务器返回的学生 ID 规范为字符串；
- 学生卡上的标签、编辑、删除、复制、生成和改写事件均使用安全字符串参数；
- 既有注册页面和服务端语法测试继续通过；
- 部署后线上页面包含修复，相关接口仍可用。
